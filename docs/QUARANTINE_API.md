# 검역관리지역 정보 API 분석

출처: 인터페이스 정의서 v1.0, [공공데이터포털 질병관리청_검역관리지역정보](https://www.data.go.kr/data/15139251/openapi.do)
(REST, JSON+XML, 무료·자동승인, 개발계정 하루 1,000건, 이용허락범위 제한 없음).
같은 내용의 [파일데이터(CSV)](https://www.data.go.kr/data/3074726/fileData.do)도 있다 (연 1회 갱신, 337행).

## 1. 오퍼레이션 두 개

| | ① 검역관리지역 설정 조회 | ② 검역관리지역 조회 (국가별 검역감염병) |
| --- | --- | --- |
| 요청주소 | `…/QuarantineRegion/DiseaseNation` | **`…/QuarantineRegion/NationDisease`** |
| 묻는 것 | 감염병·대상자 그룹별로 어느 나라·공항·항구가 대상인가 | 나라별로 어떤 검역감염병이 지정되어 있나 |
| 요청 변수 | `icdCd`(검역감염병 코드), `riskGroupCd`(대상자 그룹) | `ntnNm`(나라), `srvlncBgngYmd`(관리일자), `icdCd`, `useYn` |
| 응답 한 건 | 감염병 × 대상자 그룹 1행 + 대상 국가 목록이 **쉼표로 이어진 문자열**(`nationNm`), 공항·항구 목록, 감시기간(`srvlncPerdCnt`), 선정·해지 일시 | 나라 × 감염병 1행: `ntnNm`, `ovseaIcdKornNm`, 지정일 `srvlncBgngYmd`, 해지일 `srvlncEndYmd`, `useYn` |
| 지도 연동 | 나라 목록을 쪼개야 하고 대상자 그룹 단위라 중복이 많음 | **나라 → 감염병 구조가 지도 패널과 1:1** |

공통 요청 변수: `serviceKey`(Decoding 키), `resType`(**1=xml, 2=json**, 흔한 `type=json`이 아님), `pageNo`, `numOfRows`.
공통 응답: `header.resultCode`(00=정상), `body.items.item[]`, `totalCount`(예시 700).

**결정: 지도에는 ②를 쓴다.** `resType=2`, `useYn=Y`로 전체를 100건씩 받아(약 7회 호출) 나라별로 묶는다.
①은 대상자 그룹·공항·항구가 필요해질 때(예: "중동 방문 입국자" 안내) 확장용으로 남긴다.

## 3. 처리 규칙과 주의점

| 주의점 | 처리 |
| --- | --- |
| 응답 형식 변수가 `resType`(1/2) | 수집 스크립트가 `resType=2`를 항상 넣는다 |
| 해지된 지정도 남아 있음 | `useYn=Y`이고 해지일이 비었거나 기준일 이후인 것만 "현재 지정"으로 표시 |
| 날짜 형식이 섞일 수 있음 (`2024-09-02`, `2023-11-01 00:00`) | 숫자 8자리로 정규화 |
| 나라가 한글 이름(`베트남`) | `config/country_names_ko.json`(약 200개국)으로 ISO-3 변환 → 지도 색칠. 못 바꾼 나라는 `reports/quarantine_report.md`에 남기고 목록에서는 고를 수 있게 함 |
| 에러는 `resultCode`로 옴 (101 키 없음, 102 인증 오류, 30 미등록 키, 22 호출 한도 초과) | `kdca_api.extract_items`가 코드·메시지를 그대로 알려 줌 |
| 오퍼레이션 이름은 정의서에 없고 활용신청 상세기능에만 있음 | 확인 결과 ② `NationDisease`, ① `DiseaseNation`. 스크립트 기본값이 `…/QuarantineRegion/NationDisease`이고, 설정이 TODO이거나 기본 주소만 있어도 이 주소를 쓴다 |
| 검역관리지역은 "검역법에 따라 WHO·현지 공관의 발생 정보를 기준으로 지정한 지역"이다 | 화면에서는 "위험도"가 아니라 "검역관리지역 지정"으로 표현하고 기준일·출처를 함께 표시 |

## 4. 실행

```bash
# API (.env에 DATA_GO_KR_SERVICE_KEY = Decoding 키)
python -m scripts.fetch_quarantine
# API 승인 전: 파일데이터 CSV를 내려받아
python -m scripts.fetch_quarantine --csv data/raw/csv/검역관리지역정보.csv
```

결과 `data/processed/country_watch.json`을 화면이 바로 읽는다 (Streamlit 새로고침).
