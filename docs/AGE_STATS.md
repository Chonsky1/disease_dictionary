# 연령별·시기별 통계 (단계 2)

감염병포털에서 내려받은 통계 파일을 `data/raw/stats/`에 이름 그대로 넣고
`python -m scripts.build_age_stats`를 실행하면 `data/processed/age_stats.json`이 만들어지고,
화면의 **연령별 알아보기**가 이 파일을 읽는다. 파일 종류는 이름이 아니라 내용(상단 '감염병', '조회기간', '조회구분')으로 판별한다.
xlsx는 표준 라이브러리만으로 읽는다 (`data_prep/xlsx_lite.py`, 새 라이브러리 없음).

## 1. 받은 파일 30개 분석

| 종류 | 파일 | 연령 | 화면에서 쓰임 |
| --- | --- | --- | --- |
| 전수감시 성별·연령별 | 기본통계_성별_연령별.csv | 14개 연령대 × 남·여 | 연령대별 많이 신고된 감염병, 감염병별 연령 분포 |
| 성매개감염병 표본감시 | 임질, 클라미디아감염증, 연성하감, 성기단순포진, 첨규콘딜롬, 사람유두종바이러스감염증, 매독(1기·2기·선천성) | 14개 연령대 × 남·여 (주별, '계' 행 사용) | 같은 두 화면 ('자료'에서 고름) |
| 중증급성호흡기감염증 | 절기별 7개 파일 (2021-2022 ~ 2026-2027) | 0세, 1-6세, 7-12세, 13-18세, 19-49세, 50-64세, 65세 이상 | 감염병별 연령 분포 + 유행 시기 |
| 인플루엔자 의사환자분율 | 인플루엔자 선택됨.csv | 없음 (전체) | 유행 시기 |
| 연도별 주간 의사환자분율 | 수족구병, 안과감염병 | 없음 | 유행 시기 |
| 병원체 주별 검출 | 급성호흡기(바이러스·세균·인플루엔자·코로나19), 엔테로바이러스, 장관감염증, 기생충감염증 | 없음 | 유행 시기 |
| 사용 안 함 | 의료관련감염병(월별 발생률), 합병증동반 수족구병(연도 합계), 해외유입기생충감염증(성별·주별, 건수가 매우 적음) | - | - |

## 2. 주의점과 처리

| 주의점 | 처리 |
| --- | --- |
| 기본통계 CSV에 **머리글이 없음** (68열) | 법정감염병 목록 순서와 값의 특징으로 열 이름을 추정해 `config/age_stats_columns.json`에 둠: 1급 16열(신종감염병증후군·니파 제외), 2급 21열(결핵 제외), 3급 31열(AIDS 제외), 매독은 1기·2기·선천성·잠복·3기. 근거 예: 수두·성홍열은 0~9세, 폐렴구균·CRE·쯔쯔가무시·SFTS는 65세 이상, 말라리아·엠폭스는 남성, 선천성 매독은 0~4세 1건. 화면에 "추정"으로 표시하고, 포털 머리글로 확인하면 `verified: true` |
| 기본통계의 조회 기간이 파일에 없음 | `config/age_stats_columns.json`의 `period`에 적으면 화면에 표시 |
| 숫자에 쉼표(`4,983`), 빈 값 `-`, 최근 주 `집계 중` | 숫자로 바꾸고 `-`·`집계 중`은 빈 값 |
| 절기 파일이 서로 겹침 (같은 절기가 여러 파일에) | 빈 칸만 채워 합침 |
| 절기 = 그해 36주 ~ 다음 해 35주 (53칸, 53주는 있는 해만) | 인플루엔자 CSV의 53칸도 같은 순서. 2024-2025절기 정점 99.8이 2025년 1주로 맞는 것으로 확인 |
| 신고 건수 ≠ 발생률 (연령대 인구가 다름), 표본감시 = 일부 기관 신고 | 화면 부제·정보 창에 "인구 대비 발생률이 아님", "표본감시 기관 신고 건수"를 표시 |
| 병원체 이름이 법정감염병 이름과 조금 다름 (`마이코플라즈마균` 등) | `PATHOGEN_ALIASES`와 "이름 + 감염증" 규칙으로 연결 → 질문하기 버튼 |

## 3. 화면

| 탭 | 차트 | 정보 창 |
| --- | --- | --- |
| 연령대별 많이 신고된 감염병 | 고른 연령대·성별의 상위 10개 가로 막대 (신고 건수순 / 연령대 비중순) | 누른 감염병의 이 연령대 건수·비중, 가장 많은 연령대, 남녀 비, 연령 분포 보기, 질문하기 |
| 감염병별 연령 분포 | 연령대별 남·여 쌓은 막대 (가장 많은 연령대 강조), 중증급성호흡기는 절기별 막대 | 총 건수, 가장 많은 연령대, 10세 미만·65세 이상 비중, 남녀 비, 질문하기 |
| 유행 시기 | 해(절기)마다 한 줄, 최근 해만 진하게 | 보통 유행하는 달, 최근 집계, 해마다 정점 주, 질문하기 |

## 4. 다시 만들기

새 파일을 내려받으면 `data/raw/stats/`에 넣거나 바꾸고 `python -m scripts.build_age_stats`를 다시 실행한다.
결과 보고는 `reports/age_stats_report.md` (파일별 처리 결과, 목록과 연결 안 된 이름).
